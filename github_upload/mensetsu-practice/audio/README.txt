VOICEVOX audio files go in this audio folder.

Use these file names.

Common questions:
common-001.wav
common-002.wav
common-003.wav

Major questions:
major-001.wav
major-002.wav
major-003.wav

If a WAV file exists, the tool plays that file.
If a WAV file does not exist yet, the tool uses the browser voice.

Use only the question text in VOICEVOX. Do not include furigana.
